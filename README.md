# PrepMind AI

PrepMind AI is an AI-powered exam preparation web app built using HTML, CSS, JavaScript, and Gemini API.

## Features
- Exam Overview
- AI MCQ Generator
- Teach Me Topic Learning
- Ask Doubts Chatbot
- Progress Tracking

## Tech Stack
- HTML
- CSS
- JavaScript
- Gemini API

## Setup
1. Get Gemini API key
2. Open HTML file
3. Paste API key
4. Start learning
